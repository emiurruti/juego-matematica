# Azar en Juego

Videojuego educativo de Matemáticas centrado en **Probabilidad y Estadística**.

## Propósito
Favorecer que el estudiante interprete información, reconozca situaciones en las que interviene el azar, analice posibles resultados y tome decisiones a partir de los datos disponibles.

## Cómo jugar
1. Elegir un avatar.
2. Recorrer cinco niveles progresivos.
3. Resolver situaciones de interpretación, azar, probabilidad, detección de errores y toma de decisiones.
4. Leer la retroalimentación de cada desafío para comprender el razonamiento.

## Niveles
- Leer los datos
- ¿Azar o certeza?
- Laboratorio de azar
- Detectives de datos
- Decisiones con evidencia

## Características
Interfaz adaptable, navegación por teclado, consignas claras, retroalimentación explicativa, progresión por niveles y diseño responsive.

## Publicación
El proyecto es estático: `index.html` puede publicarse directamente con GitHub Pages.
